# UMOD GFR

Analyses statistiques (Stata) sur l'uromoduline (UMOD), la copeptine et la réabsorption d'eau, à partir des données transversales de la cohorte SKIPOGH.

## Contenu

- `stata/umod_copeptin_cross_sectional.do` : script d'analyse principal (variables, outliers, tableau 1, hypothèses 1 et 2, analyses de sensibilité).

## Données

Les données (`.dta`) ne sont pas versionnées dans ce dépôt. Le chemin vers le fichier de données est défini en tête du do-file.
